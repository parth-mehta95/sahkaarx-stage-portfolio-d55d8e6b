# Practice Scaling & Normalization

## Task Brief
Apply scaling and normalization techniques to the customer churn dataset.

## Scenario
As a data scientist, prepare the customer churn dataset for machine learning by scaling and normalizing the features.

## Deliverables
- Modified churn dataset

## Success Criteria
- Scaled features are within the range [0, 1].
- Standardized features have zero mean and unit variance.
- Code is well-documented and reproducible.
- Scaling & Normalization: Apply MinMaxScaler to numerical features.
- Scaling & Normalization: Apply StandardScaler to numerical features.
- Scaling & Normalization: Compare the results of different scaling methods.
