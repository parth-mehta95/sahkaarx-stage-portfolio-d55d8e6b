# Practice Missing Value Imputation

## Task Brief
Address missing values in the churn dataset.

## Scenario
As a data scientist, you are tasked with preparing the customer churn dataset for analysis. The dataset contains missing values that need to be addressed.

## Deliverables
- Modified churn dataset with imputed values

## Success Criteria
- Missing values are handled appropriately.
- Data integrity is maintained.
- Imputation methods are documented.
- Missing Values: Implemented missing value imputation techniques.
- Missing Values: Documented the rationale for chosen methods.
- Missing Values: Verified data integrity after imputation.
