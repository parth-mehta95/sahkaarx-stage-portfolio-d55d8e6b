# Practice Object-Oriented Programming with Churn Data

## Task Brief
Implement classes to represent customer data for the churn prediction project.

## Scenario
Design a basic data model for customer churn prediction.

## Deliverables
- Python code with defined classes

## Success Criteria
- Classes are well-defined and documented.
- Methods function correctly and handle basic data operations.
- Code adheres to OOP principles.
- Object Oriented Programming: Define classes for Customer, Transaction, and ChurnData
- Object Oriented Programming: Implement methods for data loading and basic analysis
- Object Oriented Programming: Demonstrate inheritance and polymorphism in class design
