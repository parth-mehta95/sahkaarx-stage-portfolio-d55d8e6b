# Practice Virtual Environments

## Task Brief
Configure a virtual environment for the customer churn prediction project.

## Scenario
As a data scientist, set up a dedicated virtual environment for the churn prediction project to ensure dependency isolation and reproducibility.

## Deliverables
- Functional virtual environment

## Success Criteria
- Virtual environment is correctly configured.
- Dependencies are installed without errors.
- Project runs within the virtual environment.
- Virtual Environments: Virtual environment created successfully.
- Virtual Environments: Project dependencies installed within the environment.
- Virtual Environments: Environment activated and used for project execution.
