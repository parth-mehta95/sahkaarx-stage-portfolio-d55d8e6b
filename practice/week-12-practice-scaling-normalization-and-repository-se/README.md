# Practice Scaling & Normalization and Repository Setup

## Task Brief
Apply scaling and normalization techniques to the customer churn dataset and commit the cleaned dataset to the project repository.

## Scenario
As a data scientist, you have completed cleaning and preprocessing the customer churn dataset. Now, you need to prepare it for modeling and share it with your team.

## Deliverables
- Cleaned and preprocessed dataset in a public GitHub repository

## Success Criteria
- Dataset is scaled and normalized.
- Repository is initialized with a README.
- Dataset is committed with a descriptive commit message.
- Scaling & Normalization: Dataset features are scaled to a consistent range.
